## 📌 Project Overview

Understanding financial growth and compounding effects can be confusing without visual breakdowns. This application allows users to toggle between **Simple Interest** and **Compound Interest** calculations, giving an immediate, transparent comparison of total interest earned versus total maturity amount.

---

## ✨ Key Features

- **🔄 Dual Interest Modes:** Toggle effortlessly between Simple Interest ($SI = \frac{P \times R \times T}{100}$) and Compound Interest ($A = P(1 + \frac{r}{n})^{nt}$).
- **📊 Real-Time Financial Breakdown:** Displays principal amount, total interest generated, and final maturity value instantly.
- **🎨 Modern Tailwind UI:** Styled using utility-first Tailwind CSS for a crisp, responsive layout on mobile, tablet, and desktop screens.
- **⚡ Lightweight Execution:** Instant calculations using native JavaScript DOM event listeners with zero external framework overhead.

---

## 🛠 Tech Stack

- **Markup:** HTML5 (Semantic elements & form controls)
- **Styling:** Tailwind CSS (Utility-first responsive design)
- **Logic & Calculations:** JavaScript (ES6+ DOM API)
- **Deployment:** GitHub Pages / Vercel
